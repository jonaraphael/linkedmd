LinkedMD

Export LinkedIn profiles to clean Markdown in one click. Built for recruiters, researchers, and builders who want profile data in reusable docs instead of trapped UI.

Install

Chrome Web Store

Best experience for non-technical users. One click, no developer mode.

Install LinkedMD GitHub
npm run build:cws-package
Dev Install

Arc / Chrome local install

  1. Run npm run build.
  2. Open arc://extensions (or chrome://extensions).
  3. Enable Developer mode.
  4. Click Load unpacked.
  5. Select the extension/ folder.
