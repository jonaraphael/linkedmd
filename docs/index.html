LinkedIn -> Markdown

Local-only exporter. Runs on LinkedIn profile pages while you are logged in. No servers.

1) Bookmarklet (instant)

  1. Show your bookmarks bar.
  2. Drag this button to the bookmarks bar:

Export LinkedIn -> MD

Usage: open a LinkedIn profile page (/in/...), click the bookmarklet, it downloads a .md file (and tries to copy to clipboard too).
