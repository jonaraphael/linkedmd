LinkedIn -> Markdown

Export a logged-in LinkedIn profile page into one dense .md file. Bookmarklet and userscript both run the same exporter engine.

Path 1

Bookmarklet (fastest)

  1. Open this page and wait for the button to load.
  2. Drag Export LinkedIn -> MD into your browser bookmarks/favorites.
  3. Open any LinkedIn profile URL like /in/..., then click it.
