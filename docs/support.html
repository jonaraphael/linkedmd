LinkedMD Support

Need help or want to report an issue? Start here.

Quick checks

  1. Open a profile URL that matches https://www.linkedin.com/in/....
  2. Refresh the page once before export.
  3. Click the extension icon and run Export Current Profile.

Common issues

Export button is disabled
You are likely not on a LinkedIn profile page. Open a profile URL and try again.

Export misses section content
LinkedIn UI changes can alter selectors. Capture the profile URL and file a bug with details.

No file downloaded
Check browser download permissions and popup blockers, then retry.

Report a bug

Open an issue at GitHub Issues with:

  • Browser and version (Arc/Chrome)
  • Extension version
  • Profile URL pattern (not private content)
  • What you expected vs what happened
