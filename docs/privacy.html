LinkedMD Privacy Policy

Last updated: February 9, 2026

LinkedMD exports the current LinkedIn profile page to a local Markdown file. The extension is designed for local-first operation.

What LinkedMD does

  • Reads visible content from the active LinkedIn profile tab.
  • Formats profile information as Markdown.
  • Triggers a local file download in your browser.

Data collection

LinkedMD does not intentionally collect, sell, or broker user data. This repository does not include a backend service for profile ingestion.

Website content handling

LinkedMD accesses website content on LinkedIn profile pages only to provide its single purpose: exporting the current profile to a local Markdown file. The extension does not require a project-hosted backend for normal use.

Data transmission

LinkedMD does not require an account and does not transmit exported profile data to a project-owned server during normal extension usage.

Permissions

  • activeTab and scripting are used to run export logic in the active page.
  • tabs is used for extension workflow and command handling.
  • contextMenus is used for right-click export.
  • host_permissions are limited to https://www.linkedin.com/*.

User responsibility

Use LinkedMD only on data you are authorized to access and process, and in compliance with applicable laws, platform terms, and organizational policies.

Chrome Web Store Limited Use disclosure

LinkedMD's use of user data adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is used only to provide the user-facing export functionality.
